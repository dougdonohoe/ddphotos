# Sample Photos

## About

These are sample photos installed by `ddphotos init` so the starter site has something
to show. They are used by the `vacation`, `secret` and `empty` albums defined in
`config/albums.yaml` via the `sample-base` entry in its `bases:` block.

Once you have added your own albums, you can delete this whole folder along with the
`sample-base` entry and the three starter albums in `config/albums.yaml`.
